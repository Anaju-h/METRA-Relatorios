# Evolução entre os checkpoints

O intervalo entre os dois checkpoints representa uma evolução importante do METRA.

No **Checkpoint 01**, o foco estava na definição da arquitetura, estruturação do fluxo e implementação das principais áreas da aplicação.

No **Checkpoint 02**, o sistema já pôde ser demonstrado através de um fluxo funcional integrado, incluindo a geração de um relatório técnico pelo próprio METRA.

Assim, os checkpoints registram duas fases diferentes do desenvolvimento:

**Checkpoint 01**

`Estruturação → Arquitetura → Interfaces → Fluxo inicial`

**Checkpoint 02**

`Integração → Automação → Validação → Geração de relatório`
