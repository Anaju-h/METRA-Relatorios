# Documentação do METRA

Esta pasta reúne a documentação de desenvolvimento do **METRA — Sistema Inteligente de Pós-processamento de Relatórios**.

## Estrutura

### `checkpoints/`

Contém os materiais entregues durante os checkpoints de desenvolvimento do projeto.

* `checkpoint-01/` — definição inicial da solução, requisitos, arquitetura e planejamento.
* `checkpoint-02/` — evolução funcional do sistema, implementação dos principais módulos e consolidação do fluxo.

### `arquitetura/`

Documentação relacionada à arquitetura do sistema, organização em camadas, componentes e decisões técnicas.

### `banco-de-dados/`

Documentação da estrutura de persistência, tabelas, relacionamentos e evolução do banco SQLite utilizado pelo METRA.

### `fluxo-do-sistema/`

Diagramas e documentação do fluxo principal da aplicação, desde a criação do processo até a emissão e versionamento do relatório final.

### `screenshots/`

Imagens das principais telas e funcionalidades do sistema utilizadas para documentação e apresentação.

### `apresentacao/`

Materiais utilizados na apresentação final do projeto.

### `referencias/`

Materiais de referência que podem ser armazenados no repositório sem exposição de informações confidenciais ou dados reais de clientes.

## Status

A documentação é atualizada conforme a evolução do projeto.
